# Kunshan Cultural Atlas · V2 demo

静态网页。把本文件夹中的 `index.html`、`data/` 上传到 GitHub 仓库根目录。Vercel 导入仓库，Framework Preset 选择 **Other**，Root Directory 为 `./`，无需构建命令。

## 使用

桌面上把地点卡片拖到地图，或在手机和电脑上点击卡片，地图将放大并在右侧显示介绍。点击「加入路线」才会把地点添加到下方。点击「取消选择」关闭介绍，不会清除已经加入的地点。逐个加入、移除地点、加入全部景点、随机选择 3–5 个地点或切换路线模式都会自动重算。第一个加入的地点固定为起点，其余地点在演示路网中寻找最低成本的访问顺序；连接路径可能经过未选节点。「加入全部景点」包括三个标记为示意的文化和饮食点。

地图以昆山周边矩形范围限制平移和瓦片请求 `[120.72,31.07]–[121.12,31.52]`。由于标准 OSM 瓦片是方形，边缘仍可能显示昆山以外的少量区域；这不是精确行政边界裁切。

## 数据与方法

- `data/places.geojson`：四处景区的名称和景区类别来自[昆山市政府旅游文化页面](https://www.ks.gov.cn/kss/lywh/common_tt.shtml)。坐标为原型近似展示位置，未经逐点核实。昆曲文化、奥灶面、锦溪饮食是明确标注的**示意点**，不是实际场馆或商家。
- `data/routes.json`：团队制作的 **10 条演示连接**。每段时间、文化分、步行负担均是假设值；不能当作交通或无障碍资料。
- 地图底图来自 OpenStreetMap，网页通过 CDN 加载 Leaflet。需要联网，版权信息显示在地图上。
- 路由先以 Dijkstra 求出两个选点之间的最佳连接，再枚举最多七个选点的访问顺序。最快权重=`minutes`；文化探索权重=`minutes/(1+culture)`；舒缓步行权重=`minutes+6*walking`。路线指标统计经过的演示连接，重复连接会重复计数。虚线只连接示意节点，不是道路导航。“舒缓步行”不代表老人安全或轮椅可达。

## 本地预览

在项目的父目录运行：

```bash
python3 -m http.server 8000 -d kunshan-cultural-map
```

然后访问 `http://localhost:8000`。不能直接双击 HTML，因为浏览器可能禁止 `file://` 读取数据文件。
